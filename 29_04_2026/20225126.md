## Sinh vien

## Yeu cau bai tap
Xay dung ung dung CRUD bang React va `fetch` de lam viec voi API:
- `https://jsonplaceholder.typicode.com/users`

## Cac chuc nang da hoan thanh
- Read: hien thi bang danh sach users gom `name`, `email`, `phone`.
- Create: mo popup form de them user moi.
- Update: mo popup form de sua thong tin user.
- Delete: xoa user khoi bang va cap nhat UI ngay sau khi xoa.
- Search: loc danh sach theo ten.
- Pagination: chia trang danh sach nguoi dung.
- Error handling: hien thi thong bao khi fetch, save hoac delete that bai.

## Cach cai dat va chay
```bash
npm install
npm run dev
```

## Cach build
```bash
npm run build
```

## Ghi chu ky thuat
- Su dung `async/await`, khong dung `.then()`.
- Sau `POST`, `PUT`, `DELETE` giao dien duoc cap nhat bang React state.
- Form them/sua dung chung trong modal.
- Tim kiem va phan trang duoc tinh tu danh sach state hien tai.
