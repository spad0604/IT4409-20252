# Users CRUD - 29_04_2026

React + Vite app su dung `fetch` de lam viec voi JSONPlaceholder users.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Read users from `https://jsonplaceholder.typicode.com/users`
- Create user with modal form
- Delete user from table
- Search users by name
- Async/await and UI updates after `POST` / `DELETE`
- Error handling for load, save, and delete actions
