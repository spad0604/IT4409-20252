# Frontend (React CDN)

## Chay nhanh

Mo file `index.html` bang trinh duyet sau khi backend dang chay (mac dinh http://localhost:3001).

Neu muon doi API base, sua hang:

```
const API_BASE = "http://localhost:3001/api/users";
```

## Ghi chu

- Tim kiem co debounce 500ms va giu nguyen phan trang.
- Modal dung chung cho Them/Sua.
- UI responsive voi breakpoint 768px.
